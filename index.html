    Machine Learning and Business Applications

    Seis semanas para aprender a programar en Python con Google Colab, analizar datos reales, entrenar modelos de machine learning y presentar un proyecto que muestre todo eso junto.

    26 de octubre — 4 de diciembre de 2026

    Cómo funciona

    01 Cinco sesiones de contenido. Python y Colab, análisis de datos con pandas, regresión, clasificación y árboles. Cada sesión mezcla explicación y código en vivo.

    02 Un proyecto que avanza con el curso. Desde la primera clase trabajas en equipo sobre un caso de negocio. Cada sesión termina con un taller donde aplicas lo que se acaba de ver.

    03 Sprints para monitorear, no para calificar. Tres revisiones de avance con retroalimentación tipo semáforo. Sirven para detectar problemas a tiempo; no llevan nota.

    04 Una sola evaluación. El proyecto final (notebook + presentación) es el 100% de la nota. Se presenta la primera semana de diciembre.
